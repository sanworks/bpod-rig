Bpod Settings
=============

System Settings
---------------

Settings that are global to your Bpod installation are saved in 
- Linux: `~/.config/Bpod`
- MacOS: `~/Library/Application Support/Bpod`
- Windows: `C:\Users\<User>\AppData\Local\sanworks\Bpod`

The system settings determine...

- Protocol dir
- Data dir
- Config dir
- Log dir
- Phone home
    - ID
    - Opt in



Bpod Settings
-------------

- Linux: `~/Documents/Bpod`
- MacOS: `~/Documents/Bpod`
- Windows: `C:\Users\<User>\Documents\Bpod`

Lives inside of `documents/Bpod`

- List of bpod machines
